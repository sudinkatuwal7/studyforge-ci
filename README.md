# StudyForge

> **Turn your class materials into smarter study resources.**

StudyForge is an AI-powered study platform designed to help students transform their class materials into personalized study resources and practice tests.

### What are we creating?

We are creating an AI-powered study application that allows students to upload their class materials and transform them into personalized study resources. The application will help students create resources such as study guides, summaries, flashcards, and practice quizzes based on the materials they provide.

### Who are we creating it for?

StudyForge is primarily designed for college students who want a more efficient and organized way to study and prepare for classes and exams. It can be especially useful for students who have large amounts of notes, lecture slides, and other course materials that they need to review.

### Why are we creating it?

Our goal is to make studying more efficient and personalized. Students often spend a significant amount of time reviewing their class materials and manually creating study resources. StudyForge aims to reduce some of this work by using AI to transform existing course materials into useful study tools.

We hope this allows students to spend more time understanding and practicing course material rather than spending as much time preparing their study resources.

## General Information

StudyForge is based on the following user story:

> **As a student, I want to turn my class materials into personalized study resources and practice tests so that I can study more efficiently and better understand the material.**

The main problem StudyForge intends to address is the amount of time and effort students spend turning their notes, slides, and other class materials into useful study resources.

Instead of manually creating every study guide, set of flashcards, or practice test, students will be able to use StudyForge to generate these resources from materials they already have.

## Technologies Used

StudyForge plans to use the following technologies:

- **Java** – Primary programming language for the application's backend.
- **Spring Boot** – Java framework used to create backend services and the REST API.
- **React** – Used to build the application's interactive user interface.
- **HTML, CSS, and JavaScript** – Used for the structure, styling, and functionality of the frontend.
- **PostgreSQL** – Relational database used to store users, courses, uploaded study materials, quizzes, and generated resources.
- **OpenAI API** – Used to process class materials and generate study guides, summaries, flashcards, and practice questions.
- **Docker** – Used to package parts of the application into containers so the project can run consistently across different development environments.
- **Kubernetes** – Used to manage and coordinate the application's containers as the project develops.
- **Minikube** – Used to run and test the Kubernetes environment locally during development.
- **Git** – Used for version control and tracking changes to the project.
- **Bitbucket** – Used to host the team's repository and collaborate on source code.
- **Jira** – Used to manage user stories, sprint tasks, and overall project progress.
- **Postman** – Used to test and debug backend API endpoints during development.

Additional technologies and libraries may be added or changed as the project develops.

## Features

The following are the initial features planned for our first sprint.

### 1. User Account and Login

Students will be able to create an account and log in to StudyForge. This feature will allow the application to identify individual users and associate their courses and study materials with their accounts.

### 2. Course Management

Students will be able to create and organize courses within StudyForge. This provides a way for students to separate materials belonging to different classes or subjects.

### 3. Class Material Upload

Students will be able to upload class materials such as notes and course documents. These uploaded materials will provide the content that StudyForge can use to create personalized study resources.

### 4. Study Material Organization

Students will be able to view and organize their uploaded materials by course or subject. This will make it easier to find previously uploaded course materials.

### 5. Initial Study Resource Generation

Students will have an initial way to generate a study resource from their uploaded course material. This feature will establish the foundation for more advanced AI-generated study guides, summaries, flashcards, and practice quizzes in future sprints.
